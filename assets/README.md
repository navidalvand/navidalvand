# Profile asset system

The profile uses repository-hosted SVG illustrations with a shared 900-unit canvas, dark slate surfaces, mint and blue accents, and high-contrast type. The dark cards work against GitHub light and dark themes. The header's only motion is a decorative orbit with two cycles and a reduced-motion rule. No JavaScript, external fonts, dynamic statistics, or image services are needed.

- profile-header.svg: identity and restrained motion.
- vaghty.svg: conceptual booking and business UI; not a product screenshot.
- joow.svg: conceptual messaging illustration.
- engineering.svg: four engineering disciplines.

The README retains native headings, descriptive text, alternative text, links and expandable details so the content remains useful without images. Update factual claims and links in README.md first, then the corresponding illustration text. Keep private source, internal metrics and operational details out of the public profile.

Preview SVGs in a browser at desktop and mobile widths. Check GitHub's rendered profile in light and dark mode; animation support varies by client. All SVGs are source-editable text.
