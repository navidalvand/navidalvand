# Icon sources

The catalog marks each icon's source using `icon_kind`. Devicon logos are vendored from [Devicon](https://github.com/devicons/devicon), MIT, with the existing license at [../icons/LICENSE](../icons/LICENSE). Simple Icons marks come from [Simple Icons](https://github.com/simple-icons/simple-icons), CC0; OpenAI family marks use version 13.0.0 and other marks use the develop branch as retrieved on 2026-11-25. OpenAI and Claude family entries reuse their respective brand identity rather than suggesting distinct official product logos. All other marks are original category glyphs with skill abbreviations, not official logos (including Google Antigravity). Product trademarks remain with their owners. Brand marks identify tools, not endorsement. Custom marks use the portfolio's existing dark palette.
